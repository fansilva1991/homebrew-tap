# homebrew-tap

Homebrew formulae for [@fansilva1991](https://github.com/fansilva1991)'s tools.

## Usage

```sh
brew install fansilva1991/tap/claude-switch
```

or

```sh
brew tap fansilva1991/tap
brew install claude-switch
```

## Formulae

- **claude-switch** — macOS CLI to manage and switch between multiple Claude Code
  accounts. [Source](https://github.com/fansilva1991/claude-switch).
